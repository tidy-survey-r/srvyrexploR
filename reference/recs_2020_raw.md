# Residential Energy Consumption Survey (RECS) (2020) data

2020 RECS microdata

## Usage

``` r
recs_2020_raw
```

## Format

A data frame with 18496 rows and 789 variables. See "Variable and
response codebook" at
<https://www.eia.gov/consumption/residential/data/2020/index.php?view=microdata>
for variable information.
